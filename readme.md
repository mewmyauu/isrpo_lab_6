## Что изучено

цикл `for` нужен, когда заранее известно, сколько раз повторять действие.

цикл `while` проверяет условие до выполнения тела и подходит, когда число повторений неизвестно. например, чтение чисел до ввода 0. 

цикл `do while` проверяет условие после тела, поэтому выполняется минимум один раз. 

`break` досрочно выходит из цикла, а continue пропускает только текущий шаг.
